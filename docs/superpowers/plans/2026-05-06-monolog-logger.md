## Task 2: Wire Monolog in `public/index.php`

**Files:**
- Modify: `public/index.php`

- [ ] **Step 1: Replace `StderrLogger` construction with Monolog**

Current `public/index.php` contains:

```php
<?php

declare(strict_types=1);

require __DIR__ . '/../vendor/autoload.php';

use Composerd\App;
use Composerd\Config;
use Composerd\StderrLogger;
use Composerd\Storage;
use Dotenv\Dotenv;
use Laminas\Diactoros\ServerRequestFactory;
use Laminas\HttpHandlerRunner\Emitter\SapiEmitter;

$root = dirname(__DIR__);
chdir($root);
if (file_exists("$root/.env")) {
    Dotenv::createImmutable($root)->load();
}

$logger = new StderrLogger();
$config = new Config($_ENV + $_SERVER);
$fs = (new Storage($_ENV + $_SERVER))->make($config->storageDsn());
$router = App::router($config, $fs, $logger);

$request = ServerRequestFactory::fromGlobals();
$response = App::safeDispatch($router, $request, $logger);
(new SapiEmitter())->emit($response);
```

Note that the current file actually uses `RepAhead\…` namespaces (the namespace rename already landed). Read the file first, but the structure is what matters: there are imports for `App`, `Config`, `StderrLogger`, `Storage`, `Dotenv`, `ServerRequestFactory`, `SapiEmitter`, then a `chdir` + dotenv block, then the `$logger = new StderrLogger();` line, then the wiring + dispatch.

Replace the `StderrLogger` import line and the `$logger = new StderrLogger();` line. The new file should look like this in full:

```php
<?php

declare(strict_types=1);

require __DIR__ . '/../vendor/autoload.php';

use Dotenv\Dotenv;
use Laminas\Diactoros\ServerRequestFactory;
use Laminas\HttpHandlerRunner\Emitter\SapiEmitter;
use Monolog\Formatter\JsonFormatter;
use Monolog\Handler\StreamHandler;
use Monolog\Level;
use Monolog\Logger;
use RepAhead\App;
use RepAhead\Config;
use RepAhead\Storage;

$root = dirname(__DIR__);
chdir($root);
if (file_exists("$root/.env")) {
    Dotenv::createImmutable($root)->load();
}

$handler = new StreamHandler('php://stderr', Level::Debug);
$handler->setFormatter(new JsonFormatter());
$logger = new Logger('repahead');
$logger->pushHandler($handler);

$config = new Config($_ENV + $_SERVER);
$fs = (new Storage($_ENV + $_SERVER))->make($config->storageDsn());
$router = App::router($config, $fs, $logger);

$request = ServerRequestFactory::fromGlobals();
$response = App::safeDispatch($router, $request, $logger);
(new SapiEmitter())->emit($response);
```

Use `Read` then `Write` (full overwrite) — the file is short. Or use `Edit` for a surgical swap of the import line and the construction line. Either way is fine; the diff should affect only the imports and the four-line logger construction.

- [ ] **Step 3: Manually verify the new logger writes JSON to stderr**
